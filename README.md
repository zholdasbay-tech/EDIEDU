# EdiEdu

**Дневник самочувствия для школьников.** 30 секунд в день: сон, настроение, стресс, энергия, учёба, экран, движение. EdiEdu ищет закономерности на данных самого ученика, считает индекс перегрузки, помогает проверять изменения маленькими экспериментами. Школьному психологу он даёт анонимную картину по классам.

VENTUREHACK 2026 · направление «Мониторинг здоровья и персональное управление состоянием».

## Проблема → решение → аудитория → MVP

| | |
|---|---|
| **Проблема** | Перегрузку у школьников (СОЧ, пробные ЕНТ, репетиторы, недосып) замечают слишком поздно: и сами ученики, и школа. Общие советы вроде «спи больше» не отвечают на вопрос, что влияет именно на тебя. |
| **Решение** | Короткий ежедневный дневник + личная статистика: норма человека, найденные связи, индекс перегрузки с объяснением, эксперименты «до/во время». Для школы: агрегаты по классам с k-анонимностью. |
| **Аудитория** | Ученики 8–11 классов (пользователи, бесплатно). Школьные психологи и администрация (покупатели лицензии). |
| **MVP** | Работающий сайт: регистрация, отметки, 5 экранов ученика, панель психолога, методика, API с документацией, 23 автотеста. |

## Что умеет MVP

**Ученик**
- Отметка дня: 8 показателей, метки, личная заметка. Можно заполнить пропуски за 7 дней.
- «Моя картина»: индекс перегрузки 0–100 с причинами, графики за 5 недель с личной нормой, календарь настроения, ритм недели.
- «Закономерности»: связи вроде «в дни, когда ты спишь меньше 7 часов, стресс 3,1 против 2,0». Спирмен + поправка Бенджамини–Хохберга, слабые сигналы подписаны как «пока намёк».
- «Эксперименты»: 7–21 день, сравнение с 14 днями до старта (тест Манна–Уитни).
- Сигнал заботы: при устойчиво плохом состоянии показывает телефоны доверия 150 и 111.
- Профиль: присоединиться к классу по коду, включить или выключить передачу данных школе, скачать все данные, удалить аккаунт.

**Школьный психолог**
- Тепловая карта «класс × неделя» по стрессу, сну, настроению и доле перегруженных.
- Автоматические сигналы, когда в классе резко растёт напряжение, с подсказкой по меткам («период контрольных»).
- k-анонимность (k = 5), без имён, логинов и заметок.

## Запуск локально

Нужен Python 3.11+.

```bash
cd backend
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000. Кнопка «Посмотреть демо ученика» создаёт демо-аккаунт, «Открыть демо-панель психолога» открывает демо-школу. Документация API: http://127.0.0.1:8000/docs

Тесты:

```bash
cd backend
pytest -q
```

## Деплой (бесплатно, ~10 минут)

1. Залить репозиторий на GitHub.
2. На [render.com](https://render.com): **New → Blueprint** → выбрать репозиторий. `render.yaml` уже настроен.
3. Через несколько минут появится ссылка вида `https://edieedu.onrender.com`.

На бесплатном тарифе сервер засыпает через 15 минут без запросов, первое открытие после этого занимает около 30–50 секунд. **Откройте ссылку за минуту до показа.** База SQLite на бесплатном тарифе обнуляется при перезапуске. Для MVP это нормально, демо-данные создаются заново автоматически.

Альтернатива: `docker build -t edieedu . && docker run -p 8000:8000 edieedu`.

## Честность и границы

- **Не медицинское изделие.** Индекс перегрузки помогает вовремя заметить неладное, но не ставит диагноз. Веса индекса выбраны командой по смыслу, а не обучены на данных.
- **Демо-данные синтетические.** Их генерирует `seed.py`. Тесты проверяют две вещи: аналитика находит заложенные связи, а на чистом шуме не выдумывает их. Эффективность на реальных людях мы не заявляем, её нужно проверять на пилоте.
- **Связь ≠ причина.** Поэтому в продукте есть эксперименты.

## Сторонние технологии

FastAPI, Uvicorn, Pydantic, pandas, NumPy, SciPy, SQLite, шрифты Google Fonts (Literata, Onest, Caveat). При разработке использовался ИИ-ассистент (Claude) для помощи с кодом и текстами. Подробное разграничение приведено в `frontend/method.html` → «Что сделали мы и что взяли готовое».
